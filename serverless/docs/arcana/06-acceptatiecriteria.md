# Arcana Mirror — Acceptatiecriteria

De app is pas klaar als:

1. Startpagina opent zonder fout.
2. Gebruiker kan test starten.
3. Precies 120 vragen worden getoond.
4. Alle vraagtypes werken.
5. Antwoorden worden opgeslagen.
6. Gebruiker kan terug en vooruit.
7. Progressbar werkt.
8. Test kan worden gepauzeerd en hervat.
9. Resultaat pas na alle vragen.
10. Scoring geeft 30 subdimensies.
11. Scoring geeft 12 hoofddimensies.
12. Archetype-detectie werkt.
13. Stress-archetype werkt.
14. Spanningsvelden worden gedetecteerd.
15. Response quality werkt.
16. Rapport heeft alle secties.
17. Rapport bevat geen null, undefined of NaN.
18. Rapporttekst voelt persoonlijk en specifiek.
19. Rapport is niet alleen positief.
20. Rapport geeft schaduwkant en groeipad.
21. Privacytekst aanwezig.
22. Disclaimer aanwezig.
23. Print/PDF-layout werkt.
24. UI werkt goed op mobiel.
25. Build werkt.
26. Geen console errors.
27. README bevat lokaal starten.
28. README bevat deploy-instructies.
29. DECISIONS.md is bijgewerkt.
30. PROJECT_STATUS.md is bijgewerkt.
