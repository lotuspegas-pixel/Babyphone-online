# Arcana Mirror — Master Visie

Arcana Mirror is een persoonlijke spiegelmachine.

Het moet niet voelen als een simpele quiz, maar als een diep rapport dat patronen blootlegt.

De test moet gebruikers inzicht geven in:
- wie ze zijn;
- wat hen drijft;
- waar ze energie van krijgen;
- wat hen leegtrekt;
- hoe ze denken;
- hoe ze voelen;
- hoe ze reageren onder druk;
- wat anderen aan hen zien;
- wat anderen vaak niet zien;
- welke sterke kanten ze hebben;
- welke schaduwkant ze vermijden;
- hoe ze verbinden;
- hoe ze werken;
- hoe ze communiceren;
- waar hun groei ligt.

De test moet mensen niet in rigide hokjes stoppen.
Archetypes zijn alleen een presentatievorm.
De echte analyse komt uit continue scores, combinaties en spanningsvelden.

Het rapport moet raken door:
- combinatieclaims;
- innerlijke tegenstrijdigheden;
- schaduwkant;
- stressreacties;
- sociale spiegel;
- groeisleutels;
- concrete voorbeelden.

Vermijd:
- medische diagnoses;
- pseudo-spirituele claims;
- algemene "je bent soms dit en soms dat"-zinnen;
- teksten die op iedereen passen;
- kopieën van bestaande persoonlijkheidssystemen.

Gebruik de formule:

Eigenschap → zichtbaar gedrag → verborgen behoefte → effect op anderen → valkuil → groeisleutel
