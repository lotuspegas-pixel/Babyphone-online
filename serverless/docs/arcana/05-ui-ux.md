# Arcana Mirror — UI/UX

## Schermen

### 1. Startscherm
- Titel: Arcana Mirror
- Ondertitel: Een persoonlijke spiegel voor je patronen, kracht en groeirichting.
- Uitleg: Beantwoord 120 vragen. Je ontvangt daarna een persoonlijk rapport over je drijfveren, denkstijl, relaties, stresspatronen, sterke kanten en blinde vlekken.
- Toon: duur ongeveer 20-25 minuten, geen diagnose, antwoorden worden standaard lokaal opgeslagen.
- Knop: "Start mijn analyse"

### 2. Testscherm
- één vraag per scherm
- progressbar
- vraagnummer
- vorige/volgende
- autosave
- mobiel goed bedienbaar

### 3. Laadscherm
Toon 5-8 seconden rustige teksten: "Je antwoorden worden gespiegeld…", "Patronen worden herkend…", "Spanningsvelden worden opgebouwd…", "Je rapport wordt samengesteld…"

### 4. Rapportpagina
- hero met archetype
- score-overzicht
- radar chart / scorewiel
- archetype-card
- spanningsveldkaarten
- rapportsecties
- printknop
- antwoorden wissen

## Visuele stijl

- high-end, rustig, psychologisch
- donkerpaars / nachtblauw
- crème vlakken
- warm goud accent
- subtiele gradients, zachte glow
- moderne cards, veel witruimte
- geen goedkope tarotstijl, geen kinderachtige kleuren

## LocalStorage keys

- `arcana_answers`
- `arcana_current_question`
- `arcana_result`
- `arcana_started_at`
- `arcana_completed_at`

## Knoppen

Start test, Vorige, Volgende, Pauzeren, Verdergaan, Opnieuw beginnen, Rapport printen, Antwoorden wissen.

## Privacytekst

"Je antwoorden worden standaard alleen in deze browser opgeslagen om je rapport te maken. Verwijder je je browserdata of klik je op 'Antwoorden wissen', dan verdwijnen je antwoorden."

## Disclaimer

"Arcana Mirror is bedoeld voor zelfreflectie en persoonlijke ontwikkeling. Het is geen medisch, psychologisch of therapeutisch diagnose-instrument."
